Molecular Structure Drawing Tool

Turn a SMILES string into a 2D diagram and an interactive 3D model, right in the browser — no server required.

An interactive 3D model will appear here.

Built by Subodh Niroula. 2D rendering runs on RDKit.js, 3D rendering on 3Dmol.js — both entirely client-side. 3D conformers are precomputed for the example molecules; for arbitrary SMILES this page tries a live lookup against PubChem and falls back to the 2D view if no conformer is found. For guaranteed 3D on any molecule, run the companion app.py Streamlit app locally.
