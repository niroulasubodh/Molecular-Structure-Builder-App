Molecular Structure Drawing Tool

Search a molecule by name or SMILES and get a 2D diagram and an interactive 3D model, with downloads.

An interactive 3D model will appear here.

Built by Subodh Niroula. 2D rendering runs on RDKit.js, 3D rendering on 3Dmol.js — both client-side. 3D conformers are precomputed for the example molecules; name searches and custom SMILES use a live lookup against PubChem and fall back to the 2D view if no 3D record exists. For guaranteed 3D on any molecule, run the companion app.py Streamlit app locally.
